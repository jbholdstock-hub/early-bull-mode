Deploy to GitHub Pages (100% Free)

This entire dashboard is a self-contained single-file HTML application with embedded styling, charts, and simulated live data. No build step or Node.js server required:

  1. Create a free repository on GitHub.com named bull-scanner.
  2. Save this code into a file named index.html and upload it to the repository.
  3. Go to Settings → Pages.
  4. Under Build and deployment, set Source to "Deploy from a branch", select main branch, and click Save.
